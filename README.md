# ⚽ بوت مباريات برشلونة والاتحاد

بوت تيليجرام يرسل لك تنبيه قبل كل مباراة بيوم لبرشلونة والاتحاد.

## 📦 التثبيت

```bash
cd telegram-match-bot
pip install -r requirements.txt
```

## 🔑 الإعدادات المطلوبة

### 1. مفتاح API-Football (مجاني)

1. ادخل على [api-football.com](https://dashboard.api-football.com/register)
2. سجل حساب مجاني (100 طلب/يوم)
3. انسخ المفتاح من Dashboard
4. الصقه في `config.py` → `FOOTBALL_API_KEY`

### 2. توكن بوت تيليجرام

التوكن موجود في `config.py`. تأكد إنه صحيح.

## 🚀 التشغيل

```bash
python bot.py
```

## 📱 الاستخدام

1. افتح البوت في تيليجرام
2. أرسل `/start` للتسجيل
3. البوت يفحص تلقائياً كل يوم الساعة **9 مساءً**
4. إذا فيه مباراة بكره → يرسل لك تنبيه مع شعار الخصم

### الأوامر

| الأمر    | الوصف                          |
| -------- | ------------------------------ |
| `/start` | تسجيل وترحيب                  |
| `/check` | فحص يدوي لمباريات بكره         |
| `/today` | فحص مباريات اليوم              |
| `/help`  | عرض المساعدة                   |

## 🔧 تخصيص

- غير وقت الفحص اليومي من `config.py` → `CHECK_HOUR` و `CHECK_MINUTE`
- أضف فرق جديدة في `TEAMS` (ابحث عن team_id من [api-football](https://www.api-football.com/documentation-v3#tag/Teams/operation/get-teams))
- غير المنطقة الزمنية من `TIMEZONE`
